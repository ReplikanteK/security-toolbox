About

Security Toolbox is a collection of free, privacy-first security tools for bug bounty hunters, penetration testers, and developers.

Why we built this

Every security professional needs quick access to tools like JWT decoders, hash identifiers, and CVE search. Existing options are often slow, cluttered with ads, or send your data to a server. We wanted something fast, clean, and private — where everything runs in your browser.

Privacy First

All tools process data client-side. No data leaves your browser except when you explicitly use a tool that queries external APIs (DNS, CVE, CORS proxy). We have no backend, no database, no analytics, and no tracking.

Built by a Bug Bounty Hunter

These are the tools I reach for daily when analyzing targets on HackerOne, Bugcrowd, Intigriti, and YesWeHack. Each tool solves a real problem from actual security research.

Open Source

This project is fully open source on GitHub. Contributions, feature requests, and bug reports are welcome.
