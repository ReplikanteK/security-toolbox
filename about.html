About

Security Toolbox is a collection of free, privacy-first security tools — built by a bug bounty hunter, for bug bounty hunters and developers.

Why this exists

Every tool here was born from a real need during security research. When analyzing targets on HackerOne, Bugcrowd, Intigriti, and YesWeHack, I kept reaching for the same tools over and over: JWT decoders, DNS lookups, hash identifiers. Existing options were either slow, cluttered, or sent your data to a server.

So I built my own. Everything runs in your browser. No data leaves your machine unless you explicitly query an API (DNS, CVE, etc.).

Built from experience

The tools reflect actual bug hunting patterns discovered across 59 research sessions:

  • JWT Attacker — from testing auth bypasses on multiple platforms
  • GraphQL Introspection Checker — from API recon on GraphQL-based targets
  • Redirect Chain Analyzer — from finding open redirects in real programs
  • CSP Evaluator — from analyzing security headers during recon
  • Payload Builder — curated from payloads that actually work in bug bounty

Privacy

No tracking, no analytics, no backend. Zero data collection. Most tools work entirely offline. Tools that need external APIs (DNS, CVE, CORS proxy) clearly state what data is sent and to which service.

Open Source

Every line of code is on GitHub. Contributions, feature ideas, and bug reports are welcome.

Roadmap
