What is JWT Attacker?

Test JWT security with 5 attack classes: alg:none bypass, kid injection, secret brute-force, algorithm confusion, and key injection.

FAQ

What is alg:none attack?
Setting the JWT algorithm to 'none' bypasses signature verification entirely. The server accepts any token without checking the signature.
How do I brute-force JWT secrets?
The tool tries common passwords against the HMAC signature. Weak secrets like 'secret' or 'password' are cracked instantly.
