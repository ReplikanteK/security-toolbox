Web Auditor

Comprehensive security audit for any URL. Runs DNS, SSL/TLS, security headers (A+ grade), CORS, WAF, tech stack detection, cookie analysis, CSP deep evaluation, TTFB, HTTP methods, redirect chain — then generates a full PDF-ready report with prioritized recommendations.

Enter a URL and click Run Audit. The audit checks DNS, SSL, headers, CORS, WAF, tech stack, cookies, CSP, performance, methods, and redirects. Results include a full report with prioritized recommendations. Use the Print button to export as PDF.
