What is Subdomain Scanner?

Discover subdomains using wordlist-based DNS resolution. Find hidden services, staging environments, and forgotten admin panels.

CNAME claims
Claim unclaimed CNAME targets (Heroku/S3/GitHub Pages) before attackers do
Wildcard DNS
Audit *.example.com wildcards — they can expose internal services
DNS monitoring
Monitor for unauthorized CNAME/A record changes indicating compromise
