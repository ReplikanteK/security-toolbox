FAQ

What is CVSS?
Common Vulnerability Scoring System (CVSS) is an open standard for rating the severity of security vulnerabilities. Scores range from 0 to 10.
How do I read the score?
0-3.9 = Low, 4.0-6.9 = Medium, 7.0-8.9 = High, 9.0-10.0 = Critical. Most bug bounty programs require High or Critical for meaningful bounties.
