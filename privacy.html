Privacy Policy

Last updated: May 20, 2026

1. Data Collection

SecuriTool does not collect, store, or transmit any personal data. All tools run entirely client-side in your browser. No cookies, no tracking scripts, no analytics — we do not have a server.

2. Third-Party Services

Some tools make HTTP requests to external services to provide functionality:

  • DNS Lookup — queries Cloudflare DNS-over-HTTPS (dns.cloudflare.com)
  • CVE Search — queries CIRCL CVE API (cve.circl.lu)
  • Subdomain Scanner, Port Scanner — use allorigins.win as a CORS proxy
  • GraphQL Introspection — sends requests directly to the URL you provide
  • Email Security — queries Cloudflare DNS-over-HTTPS for TXT records

The URLs you enter are sent to these services and may be logged by them. We have no control over their data practices. For details, refer to each service's privacy policy.

3. Analytics

This site uses GoatCounter for anonymous, privacy-respecting analytics. GoatCounter does not use cookies, does not track individual users, and does not collect personal data. It only counts page views and aggregates basic metrics (referrer, browser, screen size, country).

4. Advertising

This site does not currently display advertisements. If ads are added in the future, this policy will be updated.

4. Your Rights

Since we collect no data, there is nothing to access, correct, or delete. For third-party services, refer to their respective privacy policies.

5. Changes

We may update this policy. Changes will be posted here with an updated date.

6. Contact

Open an issue on GitHub.
